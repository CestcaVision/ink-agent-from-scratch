# 从零搭建终端 Agent

技术栈：TypeScript → Vercel AI SDK → React / Ink。使用 Corepack 管理 pnpm 版本。

这是你亲手实现的练习项目，完整参考项目位于 `../ink-agent-course/`。当前阶段：**06，把 DeepSeek 接入 Ink**。复用已有模型配置，将留言板升级为支持流式回答、多轮历史和取消请求的聊天界面。

## 每个阶段的工作方式

每个阶段对应 `stages/` 中的一份 Markdown，按以下顺序推进：

1. 助手先写阶段说明，包括目标、操作、代码解释、验收方法和提交命令。
2. 你先提交说明，保留动手前的学习目标。
3. 你照着说明执行命令、编写代码，遇到问题时一起排查。
4. 你完成验收，在阶段说明末尾填写实际执行记录。
5. 你再次提交，保存实现和验证结果，然后进入下一阶段。

每个阶段有两次提交：`plan: stepNN 主题` 与 `finished: stepNN 主题`。助手默认负责说明和检查，代码由你动手实现，Git 提交由你执行。

后续阶段说明在进入该阶段时逐份编写，基于你实际提交的代码继续，不提前跳过实现过程。
